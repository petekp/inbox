# Where sources disagree: engine and API

Part of [Claude Code mods](../claude-code-mods.md).

This part holds rows 1-58 and 111-119. They mostly concern the engine, the `$` API, drawing, hooks and plugins. [Clients and admin](disagreements-clients.md) holds rows 59-110.

Each row names the conflict, which source to trust, and why.

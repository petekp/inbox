# Files: shared modules for Herdr

Part of [the look map](../looks.md#files).

| File | Role |
| --- | --- |
| `hooks/herdr.ts` | Shared module. What a host reports to the Herdr pane it runs in: the `inbox` status line, the stop, the session's focus, and each row tab's count, as pane tokens in one `herdr pane report-metadata` command, or in a Herdr app terminal as `inbox.` labels in one `hc label` command. Also `delegatesInHerdr`, which asks `herdr agent list` what each delegate does and the focus its session publishes, only while one runs. For the Herdr app: `herdrTarget` picks a multiplexer pane or an app terminal, `herdrLabels` turns the tokens into terminal labels, `herdrEnvelope` builds the session file a host publishes, and `publishedSessionPath` and `pressFolder` say where the session file and press files go. |
| `hooks/herdr-press-file.ts` | Shared module. `pressFile` reads and checks a press file the Herdr look writes. Only the hosts import it, so the look's bundle leaves it out. |
| `hooks/herdr-open.ts` | Shared module. `herdrPanelOpener` opens the Herdr look to the right of a host's app terminal, or focuses the panel the terminal's `inbox.panel` label names, and gives the line the host shows. `hasHerdrMod` says whether the app home holds the inbox mod. The mod and omp call it from their open actions. |
| `hooks/herdr-app.ts` | Shared module. How a host publishes its session for the Herdr app's look, and the write, move and remove that publish and unpublish it. Over 1 MiB, `publishedText` leaves out the closed items the view does not show. `pressDrainer` takes each press file the look writes under `<app home>/inbox/presses/` by a rename, so one process applies it, `applyLookPress` applies one and saves it as the session's `lastHerdrPress`, and `followPresses` reads them at start, on each wake and every `PRESS_POLL_MS`. Each host passes its own file calls. |
| `hooks/herdr-ask.ts` | Shared module. The question a host asks before it installs the inbox's Herdr mod: `herdrAskBanner` draws it as the `herdr-mod-ask` banner in the `ask` tone, `HERDR_ASK_BUTTONS` gives Install and Don't install in order, and `answerHerdrAsk` saves the answer and installs after Install. `isHerdrAskOpen` tells a host when another session answered, `askHerdrAgain` is `/inbox herdr`, and `herdrAskInApp` is the Codex app tab's check. |
| `hooks/herdr-install.ts` | Shared module. `keepHerdrModCurrent` installs the inbox's Herdr mod from the copy a host carries into `<app home>/mods/inbox/` after the person's yes, and replaces an installed inbox build that is older by the time on its second line, or cut off short of the length that line gives. It never writes through a link or over a mod that is not the inbox's build. `answerHerdrMod` saves the person's yes or no in `<app home>/inbox/herdr-mod.json`, which every host reads. |
| `hooks/herdr-sweep.ts` | Shared module. `labelledSessions` reads every live terminal's `inbox.session` label from one `terminal.list` call through `hc connect`. `sweepPublished` removes each published session that no label names, that was written over a day ago and that another terminal published, with its press folder, and leaves any file it cannot read as the inbox's own session. `sweepModTemporaries` removes the temporary files and folders an install, update or answer left over a day before. |
| `hooks/herdr-start.ts` | Shared module. `startInHerdrApp` is what a host does once when it starts in a Herdr app terminal: it keeps the mod current and sweeps old session files, and logs what each did. Each host passes its own file calls. |

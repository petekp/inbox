# Files: shared modules for Herdr

Part of [the look map](../looks.md#files).

| File | Role |
| --- | --- |
| `core/remote/herdr.ts` | Shared module. What a host reports to the Herdr pane it runs in: the `inbox` status line, the stop, the session's focus, and each row tab's count, as pane tokens in one `herdr pane report-metadata` command, or in a Herdr app terminal as `inbox.` labels in one `hc label` command. Also `delegatesInHerdr`, which asks `herdr agent list` what each delegate does and the focus its session publishes, only while one runs, or in a Herdr app terminal asks `core/remote/hc-terminals.ts:delegatesInHc` every time. For the Herdr app: `herdrTarget` picks a multiplexer pane or an app terminal, `herdrLabels` turns the tokens into terminal labels, and `publishedSessionPath` and `pressFolder` say where the session file and press files go. |
| `core/remote/herdr-envelope.ts` | Shared module. `herdrEnvelope` builds the session file a host publishes for the Herdr look, from the session and the host's `EnvelopeSource`. |
| `core/remote/hc-terminals.ts` | Shared module. What `hc ls --json` says about the terminals that are children of the Herdr app terminal a session runs in: each one with a status, by name or else address, as an agent for `delegatesSettled`. A terminal with no status, a shell or another program, is left out, and `error` reads as blocked. Also `delegateSession`, which reads from `hc get` whether the terminal a session runs in is a delegate's. |
| `core/remote/remote-commands.ts` | Shared module. Admits version-2 row commands, checks saved command records before effects, and retains duplicate-command outcomes. Publication remains disabled until client recovery and host delivery checks pass. |
| `core/remote/remote-press.ts` | Shared module. `REMOTE_PR_ACTIONS`, `isRemotePrPress` and `isRemoteCommandPress` validate version-2 remote row, goal, PR and Resume presses before a host applies them. |
| `core/runtime/remote-command-state.ts` | Shared module. `CommandLog` and `CommandStore`, a session's command log and where a host keeps it. `remoteCommandState` brings the log up to date with the session, which is saved first. Also the receipts a publish carries, and `recoverStrandedCommands`, which marks a command whose process ended uncertain and marks Not sent what it or a command the log has no record of left to send. |
| `core/runtime/session-registry.ts` | Shared module. `RegistryEntry`, a session's entry in the session registry, and `writeRegistryEntry`, which writes it through a temporary file and a move when it changed, and then removes the entries of the same host whose process ended. Also `removeRegistryEntry`, `registryFolder` and `registryHerdr`. Each host supplies the file calls. |
| `core/runtime/command-store.ts` | Shared module. `fileCommandStore`: a command log in a file, changed under the host's lock and read back after each change, with an unreadable file moved aside. `movedLegacyCommands` moves the records an earlier build saved in the session into the log, and `followCommandRows` brings the log up to date after each save. |
| `core/runtime/remote-viewers.ts` | Shared module. Orders viewer generations and updates, expires remote draft holds using host time, and keeps their retention separate from local pane holds. `ViewerStore` is where a host keeps a session's viewer leases, apart from its saved state. `memoryViewerStores` keeps them in process memory, for the mod and omp. |
| `core/remote/herdr-labels.ts` | Shared module. `SESSION_LABEL`, the label that names the session a terminal runs, and `PRESS_LABEL`, the label the Herdr look sets after it writes a press. The host and the look both import them. |
| `core/remote/herdr-press-file.ts` | Shared module. `pressFile` reads and checks a press file the Herdr look writes: a press, a look at the Status, a collapse, or a report that the PRs tab or the Status is shown. Only the hosts import it, so the look's bundle leaves it out. |
| `core/remote/herdr-open.ts` | Shared module. `herdrPanelOpener` opens the Herdr look to the right of a host's app terminal, or focuses the panel the terminal's `inbox.panel` label names, and gives the line the host shows. `hasHerdrMod` says whether the app home holds the inbox mod. The mod and omp call it from their open actions. |
| `core/remote/herdr-app.ts` | Shared module. How a host publishes its session for the Herdr app's look, and the write, move and remove that publish and unpublish it. Over 1 MiB, `publishedText` leaves out the closed items the view does not show. `pressDrainer` takes each press file the look writes under `<app home>/inbox/presses/` by a rename, so one process applies it, `startHerdrFile` applies one, naming a press as the session's `lastHerdrPress` and counting a look at the Status as seen. Each press it applies carries the checks the look wrote, and expires `PRESS_LIFETIME_MS` after it was pressed. A message the host holds until the agent's turn ends waits outside the drain, in press order. `followPresses` reads the press files at start, on each wake and every `PRESS_POLL_MS`. Each host passes its own file calls. |
| `core/remote/herdr-ask.ts` | Shared module. The question a host asks before it installs the inbox's Herdr mod: `herdrAskBanner` draws it as the `herdr-mod-ask` banner in the `ask` tone, `HERDR_ASK_BUTTONS` gives Install and Don't install in order, with their keys y and q, `answeringOf` hides them while either press runs, and `answerHerdrAsk` saves the answer and installs after Install. `isHerdrAskOpen` tells a host when another session answered, `askHerdrAgain` is `/inbox herdr`, and `herdrAskInApp` is the Codex app tab's check. |
| `core/remote/herdr-install.ts` | Shared module. `keepHerdrModCurrent` installs the inbox's Herdr mod from the copy a host carries into `<app home>/mods/inbox/` after the person's yes, and replaces an installed inbox build that is older by the time on its second line, or cut off short of the length that line gives. It never writes through a link or over a mod that is not the inbox's build. `answerHerdrMod` saves the person's yes or no in `<app home>/inbox/herdr-mod.json`, which every host reads. |
| `core/remote/herdr-sweep.ts` | Shared module. `labelledSessions` reads every live terminal's `inbox.session` label from one `terminal.list` call through `hc connect`, and gives none unless the list holds the host's own terminal and every terminal's labels. `sweepPublished` removes each published session that no label names, that was written over a day ago and that another terminal published, with its press folder, and leaves any file it cannot read as the inbox's own session. `unpublishOthersHere` removes the published sessions of one host, other than the one that starts, that name the terminal it starts in. `sweepModTemporaries` removes the temporary files and folders an install, update or answer left over a day before. |
| `core/remote/herdr-start.ts` | Shared module. `startInHerdrApp` is what a host does once when it starts in a Herdr app terminal: it keeps the mod current and sweeps old session files, and logs what each did. Each host passes its own file calls. |

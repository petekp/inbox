# Differences on purpose: the Exact web look (private)

Part of [the look map](../looks.md#differences-on-purpose).

Status note: Exact Web is a private look (not yet publicly announced). This table compares it with the Codex tab, the nearest look.

| Topic | Exact web look | Why | Where |
| --- | --- | --- | --- |
| Session navigation and transport | Connects to `exact/bridge/server.ts` over local or private HTTPS and lists active, ended, disconnected and desktop-companion sessions in a persistent sidebar rail on wide viewports (`>= 960px`) or a Sessions view on narrow viewports. Keeps cached session snapshots and unsent drafts locally per browser profile. | One browser view serves multiple local, remote SSH and Codex companion sessions across reconnects without changing Herdr terminal focus. | `exact/app.ts:answer`, `exact/bridge/catalog.ts:sessionDirectory`, `exact/client-navigation.ts:loadSavedNavigation` |
| Open agent dialogs (`open-dialog-asks`) | When Asks is empty and the terminal reports waiting input, draws a notice directing the person to handle the prompt in Herdr instead of projecting a live dialog row or remote approval button. | Published sessions do not grant remote approval capability over an agent's active terminal prompt. | `exact/bridge/view.ts:currentView`, `exact/inbox-rows.contract` |
| Links and local snapshots (`link-open-rule`) | Runs copy through Exact's clipboard package and opens only HTTPS URLs or bounded helper-served `/api/artifact/` snapshots (including previews). Because browsers do not confirm whether `window.open` succeeded, open feedback reports "Requested opening …" instead of claiming completion. | Browsers cannot read local paths on the agent machine directly and expose no reliable cross-origin window-open confirmation. | `exact/bridge/local-actions.ts:prepareLocal`, `exact/tools/client-rules.ts:formatLocal`, `exact/bridge/artifacts.ts:artifactResponse` |
| Band and stop banners (`band-and-stop-rows`) | Draws no terminal prompt band, and renders shared stop banners from the published session with `Resume` when advertised by the host. | Exact Web runs outside the session terminal rather than beside an agent prompt. | `exact/bridge/banner-view.ts:projectBanners` |
| Hook trust (`hooks-need-trust`) | Shows no hook-trust banner for published Herdr sessions; desktop companion warnings arrive in `failure`. | Published Herdr sessions carry no Codex hook-trust state. | `exact/bridge/desktop.ts:desktopView` |
| Row title tint (`title-tint`) | Animates new-row entry with opacity and vertical slide, and shows settled state via result marks, feedback text and Undo without tinting the title ink. | Exact contracts animate layout height, background wash, slide and opacity rather than interpolating text ink color. | `exact/tools/prepare-client.ts:prepareClient`, `exact/inbox-rows.contract` |
| Tab labels (`tab-symbols`) | Wide web (`>= 960px`) shows text tab labels and badges in the top tab bar (`TabBar`). Narrow web draws icons alongside short tab labels in the bottom tab bar rather than emoji symbols. | Responsive web uses persistent top tabs on desktop widths and a mobile tab bar with vector icons on narrow screens. | `exact/tab-bar.contract`, `exact/action-icon.contract` |
| Answer buttons (`answers-side-by-side`) | Stacks every answer option as a vertical branch under the question tree rather than placing short answers side by side. | Exact contracts stack option branches cleanly across mobile and desktop widths without measuring intrinsic button text widths before paint. | `exact/row-actions.contract` |
| Status keyboard and pointer actions (`status-view-ask`, `status-goal`, `status-done-fold`, `status-parent-fold`) | Goal actions, parent/done folds and View ask respond to pointer clicks, with no keyboard row selection cursor on Status. | Keyboard cursor navigation targets Asks, Finds and PRs lists; Status is structured around goal/fold controls. | `exact/bridge/status-view.ts:projectStatus`, `exact/status-pane.contract` |
| Show explanation (`show-explanation`) | Never drawn, and shows no terminal scroll claim. | Exact Web runs apart from the Claude Code terminal, so it cannot scroll that conversation. | `exact/bridge/row-view.ts:projectRowGroups` |
| Stopped session send (`stopped-session-send`) | Shows the stopped-session message and offers `Resume` when advertised by the host, without a `Go to session` button. | Exact Web runs outside Herdr's window (and may be on another computer), so it cannot focus a local terminal pane. | `exact/bridge/banner-view.ts:projectBanners`, `exact/bridge/row-view.ts:projectRowGroups` |
| Row button hover wash | Explicitly sets `:hover` rules on row, fold and session-row buttons so Exact's default stylesheet does not paint an automatic `--exact-hover-wash` tint over rows. | Matches Codex and Herdr, where row containers do not show a grey hover fill behind the button surface. | `exact/inbox-rows.contract`, `exact/status-row.contract` |

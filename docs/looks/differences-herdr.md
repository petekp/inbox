# Differences on purpose: the Herdr look

Part of [the look map](../looks.md#differences-on-purpose).

This table compares the Herdr look with the Codex tab, the nearest look. The structure check reads the parts whose names start with `differences-herdr` as the Herdr look's table.

| Topic | Herdr look | Why | Where |
| --- | --- | --- | --- |
| Who draws | A Herdr app mod draws the inbox apart from the host, from the session file the host publishes under the app's home folder. | Herdr's mods run in Herdr's own process, so the look reaches the host's session only through a file. | `herdr/src/files.ts:readSession`, `hooks/herdr.ts:publishedSessionPath` |
| Following focus | Shows the session of the terminal last focused in the look's tab, and keeps it while the look itself has focus. Before anything in the tab had focus, it shows the first terminal with a session label. | One look pane can serve several agents in a tab. | `herdr/src/follow.ts:follow` |
| A terminal with no session | Draws a message in place of the tabs: no terminal in the tab, no inbox in the terminal with the program that runs there, or a session that ended. | The followed terminal can be any program, and a session can end while its terminal stays open. | `herdr/src/screen.ts:screenOf` |
| Presses | The look writes each press to a file under the app's home folder, then sets a label on the terminal the session file names, so the host reads it. While a row has a press out, every press button on it draws out, and the row reads "Sending…" or how the look's own opens went. A press ends when a publish names it as the last press the host handled, or shows its row changed. A press the host found already changed gets the shared stale note. A press a host took reads as not confirmed when the host's last press is a later one, or 15 seconds after its file was written. One that no host took by then, the look takes back out of the folder, so it cannot apply later, and it reads as not applied. A press on a row with a press out, or with no session to send to, is not sent, and its row says why. | The look reaches the host only through files and terminal labels, so a press waits for the next publish. A host's apply can fail without a publish, so the look cannot know more than that the press was taken. | `herdr/src/press-queue.ts:PressQueue`, `herdr/src/out.ts:settleOuts`, `herdr/src/out.ts:drawOuts` |
| Opens and copies | The look runs every copy, and every open of a link, an absolute path or a `~/` path, itself at once, and its row shows how it went. The press file carries what happened. It opens a relative path against the project folder the session file names, and sends it to the host when the file names none. | The person sees the result without waiting for a publish. A host leaves the project folder out when it has no absolute one. | `herdr/src/run-here.ts:isRunHere`, `herdr/src/run-here.ts:runHere` |
| Row motion | A row fades in as it enters and out as it leaves, over the shared enter and exit times, and keeps its height while it does. Rows always move. | gpui-kit transitions a height only between heights the mod sets, and the mod does not know a row's height, which depends on how its text wraps. The Herdr app tells a mod no reduced-motion setting. | `herdr/src/motion.ts:moveRows`, `herdr/src/paint-blocks.ts:blockEl` |
| Keys on the Status page | ← →, escape and Help's other keys work, but no key presses a Status button. Those take clicks. | The Status page selects no row, so no row's keys apply. | `herdr/src/keys.ts:keyMove` |
| Help | A "Help" button in the header opens Help in place of the tab, and reads "✕ Close help" while it shows. Help lists the keys and the marks, and no tab symbols. | The look always names its tabs in words. | `herdr/src/draw-help.ts:helpBlocks`, `herdr/src/paint-chrome.ts:headerEl` |
| The gh notice | Draws at the top of the PRs tab as a note in the warning tone, not as a banner. | The look draws banners above the tabs, for the whole inbox. The notice is about the PRs tab only. | `herdr/src/draw-prs.ts:prTabBlocks` |

# Differences on purpose: the Exact iOS look (private)

Part of [the look map](../looks.md#differences-on-purpose).

Status note: Exact iOS is a private look (not yet publicly announced). This table compares it with the Codex tab, the nearest look.

| Topic | Exact iOS look | Why | Where |
| --- | --- | --- | --- |
| Session navigation and transport | Connects to `exact/bridge/server.ts` over Tailscale HTTPS and switches sessions through a dedicated Sessions tab, retaining cached session snapshots and unsent drafts locally on device. | Mobile screen width has no persistent sidebar rail; switching sessions uses the native Sessions view without moving Herdr focus on the Mac. | `exact/app.ts:answer`, `exact/bridge/catalog.ts:sessionDirectory`, `exact/client-navigation.ts:loadSavedNavigation` |
| Open agent dialogs (`open-dialog-asks`) | When Asks is empty and the terminal reports waiting input, draws a notice directing the person to handle the prompt in Herdr instead of projecting a live dialog row or remote approval button. | Published sessions do not grant remote approval capability over an agent's active terminal prompt. | `exact/bridge/view.ts:currentView`, `exact/inbox-rows.contract` |
| Links and local snapshots (`link-open-rule`) | Runs copy through Exact's native clipboard module and opens only HTTPS URLs or bounded helper-served `/api/artifact/` snapshots (including previews) via `openURL`, reporting open status back to the row. | The iPhone cannot read Mac files directly and routes host files through scoped, read-only helper snapshots. | `exact/bridge/local-actions.ts:prepareLocal`, `exact/tools/client-rules.ts:formatLocal`, `exact/bridge/artifacts.ts:artifactResponse` |
| Band and stop banners (`band-and-stop-rows`) | Draws no terminal prompt band, and renders shared stop banners from the published session with `Resume` when advertised by the host. | Exact iOS runs on a separate device outside the agent terminal. | `exact/bridge/banner-view.ts:projectBanners` |
| Hook trust (`hooks-need-trust`) | Shows no hook-trust banner for published Herdr sessions; desktop companion warnings arrive in `failure`. | The bridge does not read the `hooksTrust` a published Codex session carries. | `exact/bridge/desktop.ts:desktopView` |
| Row title tint (`title-tint`) | Animates new-row entry with opacity and vertical slide, and shows settled state via result marks, feedback text and Undo without tinting the title ink. | Exact native views animate layout height, background wash, slide and opacity rather than interpolating text ink color. | `exact/tools/prepare-client.ts:prepareClient`, `exact/inbox-rows.contract` |
| Tab bar (`tab-symbols`) | Draws native tab bar items with SF-style vector icons and short tab labels in the mobile tab bar rather than emoji symbols. | Matches native iOS navigation conventions instead of compact emoji badges. | `exact/tab-bar.contract`, `exact/action-icon.contract` |
| Answer buttons (`answers-side-by-side`) | Stacks every answer option as a vertical branch under the question tree rather than placing short answers side by side. | Keeps tap targets generous and predictable on phone widths without pre-paint width measurement. | `exact/row-actions.contract` |
| Help entry (`help-page`) | Opens Help from the header control (`?`) and omits desktop keyboard navigation requirements, while still displaying the shared mark legend and key reference. | iOS is touch-first with no assumed hardware keyboard. | `exact/app-help.contract`, `exact/tools/help-rules.ts:helpLegend` |
| Status taps (`status-view-ask`, `status-goal`, `status-done-fold`, `status-parent-fold`) | Goal actions, parent/done folds and View ask respond to taps, with no keyboard row selection cursor on Status. | iOS Status interaction is touch-first. | `exact/bridge/status-view.ts:projectStatus`, `exact/status-pane.contract` |
| Show explanation (`show-explanation`) | Never drawn, and shows no terminal scroll claim. | Runs on iOS apart from the Claude Code terminal, so it cannot scroll that conversation. | `exact/bridge/row-view.ts:projectRowGroups` |
| Stopped session send (`stopped-session-send`) | Shows the stopped-session message and offers `Resume` when advertised by the host, without a `Go to session` button. | Runs on iOS apart from Herdr on the Mac, so it cannot focus a local terminal pane. | `exact/bridge/banner-view.ts:projectBanners`, `exact/bridge/row-view.ts:projectRowGroups` |

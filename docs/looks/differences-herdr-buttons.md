# Differences on purpose: the Herdr look's row buttons

Part of [the look map](../looks.md#differences-on-purpose).

This part of the Herdr look's table covers the buttons on a question, task or finding. Like [the rest of the table](differences-herdr.md), it compares the Herdr look with the Codex tab.

| Topic | Herdr look | Why | Where |
| --- | --- | --- | --- |
| Show explanation (`show-explanation`) | Never drawn, as in the Codex tab. After a press in the terminal, the row reads "✓ Shown in the conversation", as the terminal's row does. | The Herdr app runs apart from the Claude Code terminal, so it cannot scroll that conversation. | `herdr/src/screen.ts` |
| Undo's emptying fill in a light theme | The text color at 20% of its strength. In a dark theme it is 12%, as in the Codex tab. | The Codex tab uses 8% in a light theme. In Herdr's light themes 8% and 12% were too faint to see against the panel, and 20% was the smallest share that showed. | `herdr/src/paint-theme.ts:timeLeftFillOf` |
| Go to session (`stopped-session-send`) | A question, task or finding whose message Claude Code held after the person stopped the session reads "Not sent: you stopped this session. It takes inbox messages again after you write to it." It offers Go to session first among its buttons, which gives focus to the session's terminal, as Escape does. A PR block, its thread and check rows, the PR order's Rank again line, and a Done, while it settles in place and as its line in the Closed list, read the same words when Claude Code held their message, and offer Go to session before their other buttons. Once the person types there, Claude Code sends plugin messages again, and Send works. Unlike the terminal and desktop looks, the Herdr look draws no warning before a press. | A press in the Herdr look reaches the mod through a press file, so Claude Code cannot count it as the person's input. The Codex tab is inside the session it shows, and Codex holds no message after a stop. The published session does not carry the mod's `isSendHeld`, so the Herdr look learns of the hold only from a refusal. | `core/view/rows.ts:sessionKeyOf`, `core/view/action-plan.ts:rowKeyPlan`, `core/view/rows.ts:closedLinePlan`, `core/view/pr-press.ts:prPlan`, `core/view/pr-order.ts:rankAgainPlan`, `herdr/src/blocks.ts:sessionButtons`, `herdr/src/draw.ts`, `herdr/src/draw-prs.ts`, `herdr/src/main.ts` |

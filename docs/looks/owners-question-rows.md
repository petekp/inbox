# Owners: a question's parts on its row

Part of [the look map](../looks.md#who-owns-each-rule). The other row rules are in [Rows, presses and feedback](owners-rows-and-feedback.md).

| Rule | Owner | Read by |
| --- | --- | --- |
| An open question's or task's tree (`asks-tree`): a ◆, or □ on a task, in the row's mark column, and one connector from it through the Holds up line, directly under the title, then the context line and the answer options. Each shown answer option is a branch: its button, recommended filled, then its note. The connector ends at the last branch. A note is the description, ending "Recommended: <reason>" on the recommended one. Steps and follow-ups stay below. | The record tool's `why` argument, kept as `Item.recReason` by `core/runtime/tools.ts:recordItem` and `core/domain/ledger-update.ts:addAgentItem`, and dropped when the recommendation moves to another answer (`withRec`). `core/view/rows.ts:optionDescriptionsOf` pairs each option with its description and reason, `core/view/rows.ts:optionNote` writes each note, `rowKeyPlan` lists the options apart from the steps, and `core/view/rows.ts:rowMark` gives an open question ◆ and an open task □ in the tasks tone (`core/view/rows.ts:openMark`) while no result mark replaces it. | The terminal draws the connector with ├─, └─ and │ in `hooks/pane/pane-ask-tree.tsx`. Codex draws it with CSS lines in `codex/src/tab-ask-tree.tsx` and `codex/src/tab-css/rows.css`, omp with ├─, └─ and │ in `omp/src/panel-ask-tree.ts`, and the Herdr pane with drawn strokes in `herdr/src/paint-blocks.ts:bodyLineEl`. Desktop draws the connector with 1 pt lines in one frame per option, `hooks/pane/pane-desktop-tree.tsx` and `hooks/pane/pane-desktop-card.tsx`, as the Status tree is drawn. The frames sit inside one Box that holds the card's fill, so the app rounds the card once. |
| A question's answers side by side (`answers-side-by-side`): when two or more answers show and none has a description of its own, a look whose buttons fit one line of the tree draws them on that line, as the tree's last branch. The recommendation's reason, "Recommended: <reason>", goes on one line under them, starting at the first button's label. The recommended answer keeps "(recommended)" and its fill. Otherwise the answers stack as in `asks-tree`. | `core/view/action-plan.ts:rowKeyPlan` offers `answerRow` (`answerRowOf`), with the reason from `core/view/rows.ts:optionReasonLine`. `core/view/action-plan.ts:answersFitLine` is the fit test, which each look runs on its own widths. | The terminal and desktop measure in `hooks/pane/pane-row-keys.tsx:answersFit`, the terminal in cells and desktop by its button estimate (`desktopButtonPt`), and draw one line of buttons in `hooks/pane/pane-ask-tree.tsx:sideBySide` and `hooks/pane/pane-desktop-card.tsx`. Codex measures the drawn buttons before the page paints and when the tree's width changes, in `codex/src/tab-ask-tree.tsx:Answers`. omp measures the button cells in `omp/src/panel-ask-tree.ts:askTreeLines`. The Herdr pane gets `RowBlock.sideBySide` from `herdr/src/draw.ts:sideBySideOf`, and `herdr/src/paint-tree.ts:isSideBySide` measures the buttons. |
| A question's context line (`asks-context-line`): why the agent asked, drawn whole at the supporting level (`supporting-text`), under the title and after any Holds up line, on the selected row only. Collapsed rows draw no context. | The record tool's `context` argument, kept as `Item.context` by `core/domain/question-checks.ts:withBody`, which a record of the open question replaces. `core/view/view.ts:inboxView` sets it as `RowView.contextLine` on an open row. | All five looks, in the row's tree (`asks-tree`) after the Holds up line and before the option lines. The terminal and desktop draw it in `hooks/pane/pane-ask-tree.tsx`, which only the selected row draws, so the desktop row Client does not change. Codex draws it in the panel's `.tree` after any Holds up line (`codex/src/tab-ask-tree.tsx`), so a closing row keeps it until its panel goes. omp draws it in `omp/src/panel-ask-tree.ts`, with no line limit, since `core/domain/field-limits.ts` refuses a record whose context is over 200 characters. The Herdr pane draws it in the selected row's body after any Holds up line, in `herdr/src/draw.ts:rowBody`, at the supporting level like the option notes. |
| A question's previews (`option-previews`): the record tool's `previews` give each option an image, page or file. A question with any shows Open previews, key `o`, after its options and before its steps. It is a Local press that opens the previews page, every option's preview side by side in the comparison page's design, in the default browser. A step that opens a preview is left out of the steps. | `core/domain/option-previews.ts`, `core/domain/question-checks.ts:withBody`, `core/runtime/preview-pages.ts`, `core/view/action-plan.ts:actionsOf`, `core/view/pressed.ts`, `core/domain/help-steps.ts:localEffects` | Every host writes the page after each inbox tool call (record, close or order_prs), and names it on the item as `Item.previewPage`: the mod in `hooks/mod/mod-tool-calls.ts:runTool`, Codex in `codex/src/server.ts`, omp in `omp/src/host-sessions.ts:changeByTool`. All five looks draw the button from the plan. The Herdr pane runs the open itself, as it runs an open step (`herdr/src/draw.ts:rowDoes`). The page draws in `hooks/compare-page/script.js`. |
| A question's earlier answer (`earlier-answers`): one line on the open row, after the context, as "You answered Flick 3 days ago, in glasses-app, to “Which gesture…”", with the answer drawn as an option's label and the rest muted. A folded row and a closed one draw no line. | `core/runtime/history-store.ts:historyStep`, which each host runs on a session it is about to save, stores the best match on the item as `Item.earlier`, once. `core/domain/earlier-answers.ts:earlierLineOf` writes the line, and `core/view/view.ts:inboxView` sets it as `RowView.earlierLine` on an open row. | All five looks, in the row's tree after the context line. The terminal and desktop draw it in `hooks/pane/pane-ask-tree.tsx`, Codex as a `.context-line` paragraph with the answer in `<strong>` (`codex/src/tab-ask-tree.tsx`), and omp in `omp/src/panel-ask-tree.ts`, dim with the answer bold. The Herdr pane draws it as one muted body line in `herdr/src/draw.ts`. |
